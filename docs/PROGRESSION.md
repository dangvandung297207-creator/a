# Cẩm nang chơi — The Master Blacksmith (True Metallurgy)

## 1. Chuẩn bị xưởng

| Block | Công thức (bàn chế tạo) |
|---|---|
| Primitive Forge Hearth | đá cuội + gạch chịu lửa + lò nung |
| Bellows | ván gỗ + da |
| Basic Anvil | khối sắt + thỏi sắt |
| Quenching Barrel | ván gỗ + thỏi sắt |
| Grinding Wheel | đá + sắt + ván |
| Assembly Table | ván + bàn chế tạo + sắt |
| Tongs | thỏi sắt + đinh tán |
| Hammer (đồng/sắt/thép…) | 3 thỏi + 2 gậy |

Nâng cấp lò: Primitive (1100°C) → Iron (1250°C) → Steel (1400°C) → Master (1650°C).
Starfall Steel **chỉ** rèn được ở Master Forge.

## 2. Luyện kim: quặng → phôi

1. `Raw ore + Sand` (shapeless) → **Processed Ore**. Hợp kim:
   - Bronze = 3 processed copper + 1 processed tin
   - Steel = processed iron + coke (than cốc: nung coal block trong blast furnace)
   - Hardened = 2 processed steel + coke
   - Damascus = processed steel + processed hardened
   - Starfall = processed steel + 2 starfall shard (đào ở tầng sâu)
2. Nung processed trong **lò thường** → **Bloom**.
3. Dùng **kẹp** đặt bloom vào **lò rèn** → chờ tới vùng nhiệt cam.
4. Gắp ra **đe** → cầm **búa đập chuột trái** (hoặc mở UI đe) 6 nhát → **Billet**.

> Tay không chạm phôi >300°C sẽ **bỏng**. Hãy dùng kẹp.

## 3. Rèn tạo hình

1. Đặt billet lên đe → **chuột phải tay không** mở giao diện rèn.
2. Chọn khuôn: **S**word / **A**xe / **P**ickaxe / **R**spear / p**L**ate.
3. Rèn đủ số nhát mỗi công đoạn. Thanh nhiệt hiển thị **vùng chuẩn (sweet spot)**:
   - Đánh trong vùng chuẩn → biến dạng tốt, điểm cao.
   - Quá nguội → không hiệu quả, có thể **nứt** (mất purity).
   - Quá nóng → **oxy hóa** (mất purity), cháy thành **xỉ (slag)** nếu thành DUNG DỊCH.
4. Phôi nguội dần trên đe → gắp về lò **nung lại** (mỗi lần −2.5 điểm).
5. Đánh trong world: căn **attack cooldown** đầy để có aim tốt nhất.

Đe giới hạn trần điểm: Basic 75 / Iron 85 / Steel 95 / Master 100.
Muốn Legendary thì cần **Master Anvil + Blueprint**.

## 4. Tôi (quench)

Khi bộ phận **đã tạo hình xong + còn nóng**, dùng kẹp **chuột phải vào thùng tôi**
đã đổ dung dịch:

| Dung dịch | Tính cách |
|---|---|
| Water | Cứng + sắc, giòn hơn, nguội cực nhanh, hơi nước mù mịt |
| Oil | Cân bằng, dẻo + bền, khói đen, nguội chậm |
| Salt Water | Cứng/sắc nhất nhưng giòn |
| Herbal/Mineral Oil | Dẻo/bền cao, nguội chậm, +purity |
| Alchemical Oil | Toàn diện, +purity |
| Blood-infused | Sắc + cứng, phong cách tà thuật |
| Starfall | Mạnh nhất mọi mặt, nguội rất chậm, +purity |

Tôi sai thời điểm (quá nguội/quá nóng) làm giảm **quench quality**.

## 5. Mài

Đặt bộ phận đã tôi lên **đá mài** → mở UI → chọn **góc lưỡi 15–35°** → mài 3 lượt:
- **15°**: sắc nhất, kém bền. **25°**: cân bằng. **35°**: bền nhất, kém sắc.
- Đá mòn dần (−30 điểm nếu mòn 100%) → **ngồi + dùng đá lửa** để sửa.

## 6. Lắp ráp

Bàn lắp ráp (4 ô bộ phận + 1 ô blueprint):

- **Kiếm**: lưỡi + chắn + cán nắm + chuôi.
- **Rìu/Cuốc**: đầu + cán.
- **Giáo**: mũi + cán + dải da.
- **Giáp**: tấm + 2 dải da + **chọn món** (Helm/Chest/Legs/Boots).

Ô blueprint: đặt blueprint **khớp loại** (King's Edge cho kiếm…) để:
mở khóa **LEGENDARY** (không blueprint thì tối đa 89) và đặt tên riêng.
Blueprint **không bị tiêu hao**.

## 7. Tiers

- **FLAWED (0–39)**: yếu, sứt mẻ.
- **STANDARD (40–69)**: ngang vanilla.
- **MASTERWORK (70–89)**: +25% bền, +15% sức mạnh, âm hoàn thành riêng.
- **LEGENDARY (90–100)**: vượt trội, tên riêng, chữ ký người rèn.

## 8. Late game & tự động

- Bễ **cấp redstone** sẽ tự bơm theo nhịp (không cần minigame cho đồ thường).
- Phễu (hopper) tương tác được với lò/đe/đá mài/bàn ráp.
- Dân làng **Master Smith** (nhận việc ở đe thép) trade coke, dầu tôi, blueprint.
- **Thợ rèn lữ hành** lang thang Overworld bán búa, dầu, blueprint ngẫu nhiên.
- **Tàn tích lò rèn** ngoài tự nhiên: gạch chịu lửa, đe cũ, rương (coke, thép, blueprint).
- Nhật ký (`Blacksmith's Journal`) tra cứu mọi thông số + kiểm định món đang cầm.
